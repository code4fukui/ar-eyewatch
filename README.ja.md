# ar-eyewatch

A-Frameを使用して現在時刻を表示するWebARプロジェクトです。

## デモ
https://code4fukui.github.io/ar-eyewatch/

## 特徴
- WebAR環境で現在時刻を表示します
- 仮想現実（VR）体験を構築するためのWebフレームワークであるA-Frameを使用しています

## 使い方
1. WebAR対応ブラウザ（例: WebXRが有効なChromeやFirefox）でデモリンクを開きます。
2. WebAR環境に現在時刻が表示されます。
